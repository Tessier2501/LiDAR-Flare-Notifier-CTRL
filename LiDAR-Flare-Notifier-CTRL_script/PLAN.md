# 跳伞着陆动作提醒装置开发计划书

## 1. 项目目标

开发一款跳伞着陆动作提醒装置，辅助使用者把握着陆前拉平动作的时机，并在多人低可见度跳伞时提供位置辨识信号。

## 2. 功能需求

### 2.1 着陆动作提醒

1. 获取传感器测得的目标距离，并检查数据有效性。
2. 处理数据，可能包括滤波 / 斜距转高度 / 变化率等。
3. 根据有效距离及其变化趋势，输出两档蜂鸣提醒。

### 2.2 独立爆闪灯

1. 爆闪灯用于多人低可见度环境下的相互辨识。
2. 爆闪灯由独立开关控制，可单独开启或关闭。
3. 爆闪灯的开关与驱动不依赖着陆提醒状态机。

### 2.3 参数配置与固件更新

1. 电池仓内设 USB-C，直连电脑免驱修改参数、烧写固件。

## 3. 硬件架构

### 3.1 选品

- 测距传感器：PTGL-100（IEC 60825-1 Class 1 激光，直视安全）。
- 主控：STM32G431CBT6（128 KB Flash / 32 KB RAM，USB FS）。
- 备用主控：STM32G0B1CBT6（128 KB/144 KB，无 FPU）；STM32L433CCT6（256 KB/64 KB）。
- 通信：测距传感器侧 UART；参数配置与固件升级走 USB-C（免驱 CDC/HID）。
- 输出：蜂鸣器选品待决，是否有独立驱动板待决；爆闪灯选品待决。

## 4. 使用情景

以下所有数值作为保守出厂设置使用。

### 4.0 起跳之前

- 设备在起跳前开机，进行自检，输出自检结果。
- 除非代价过高，否则设备在此阶段不应解除保险。

### 4.1 自由落体阶段

- 爆闪灯由独立开关控制，全程运作。
- 跳伞者在一定高度（和装置无关）开伞。
- 由跳伞者的肢体等导致的短时回波不应引发警报。
- 除非代价过高，否则设备在此阶段不应解除保险。

### 4.2 匀速下落阶段

- 在约 100m 高度测距传感器收到有效回波，设备解除保险。
- 进入稳态后参考下降率为 6m/s。

### 4.3 着陆阶段

- 在约 4m 处装置发出蜂鸣一档，示意跳伞者开始拉绳。
- 在约 2m 处装置发出蜂鸣二档，示意跳伞者完全拉绳。
- 具体提醒距离根据下降率修正，默认调整值为零。

## 5. 固件设计方案

### 5.1 数据采集与有效性检查

- 使用 UART DMA 接收连续字节流，按帧头重同步并校验；坏帧不丢弃后续数据。
- 启动：EN 拉低后发连续测距命令；唤醒后需重新发命令；下降过程中不得进入低功耗。
- 无帧超过时间窗或命令无响应判链路故障；有帧但测量失败记测量无效，两者区分处理。

### 5.2 距离处理与提醒状态机

- 无效分短时与持续两档：短时（身体遮挡等）降级、持续判故障，时间窗待标定。
- 各档提醒设置进入阈值、退出阈值和迟滞，防止临界距离处反复切换。

### 5.3 抽象边界

- 可移植性不是设计目标，不为潜在的处理器更换牺牲必然的程序简洁性。
- 硬件定型后重新审计 port/fake 边界，删除/重构没有当前职责的抽象。
- 斜距转高度只采用常数安装角修正，已确认动态误差不超过安全阈值。
