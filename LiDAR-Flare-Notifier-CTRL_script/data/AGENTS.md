# data

测试数据与记录：台架抓包、跳伞/下降数据、标定结果。

## 1. 结构

```text
data/
|-- AGENTS.md
`-- <YYYY_MM_DD>_<主题>/
    |-- notes.md    分析笔记
    `-- ...         原始数据与分析产物
```

- 原始采集只增不改；分析产物可重新生成。
- 大文件与一次性数据放 `../temp/`。
- 数据不写入固件子模块。

## 2. 命名

- 目录 `<YYYY_MM_DD>_<主题>`；分析笔记 `<YYYY_MM_DD_HHMM>_<主题>.md`。
- 设备按序列号区分（SDFM 读回的 S 编号、固件版本），不用 COM 号或系统显示名。

## 3. 记录

- 每次采集记录时间、设备序列号、固件版本、环境与操作步骤。
- 笔记中过时或无用信息果断删除。
